# Avaliação de nível de satisfação

## Descrição

Desenvolvemos um Projeto de Sistemas de Informação utilizando JavaScript, HTML e CSS, uma colaboração entre [Caio Balieiro](https://github.com/CaioBalieir0), [Gabriel Apolinário](https://github.com/GabrielApolinario08), [Carlos Oliveira](https://github.com/caduoliveira01) e [Felipe Tavares](https://github.com/FelipeBR777). Este programa proporciona um site dedicado à avaliação do nível de satisfação do cliente em relação aos serviços prestados, apresentando, de forma visual, um gráfico que ilustra a quantidade de pessoas satisfeitas e insatisfeitas com a empresa. O sistema foi construído utilizando as tecnologias HTML, CSS, JavaScript e Bootstrap, e para gerar os gráficos de satisfação, utilizamos a biblioteca JavaScript Chart.js com armazenamento dos dados no LocalStorage.

## Funcionalidades

* **Formulário de Avaliação:** Os clientes podem responder a perguntas relacionadas à qualidade dos serviços prestados.
* **Exibição de Gráfico de Satisfação:** Após a conclusão da avaliação, um gráfico é gerado para mostrar a satisfação geral dos clientes.
* **Armazenamento Local:** As respostas dos clientes são armazenadas no LocalStorage, permitindo a visualização do gráfico mesmo após o fechamento e reabertura do navegador.

## Tecnologias

* **HTML/CSS:** Estruturação e estilização das páginas web.
* **JavaScript:** Lógica de interação e manipulação do DOM.
* **Bootstrap:** Framework CSS para um design responsivo e moderno.
* **Chart.js:** Biblioteca JavaScript para geração de gráficos.
* **LocalStorage:** Armazenamento local de dados no navegador.

## Instalação

1. **Clone o Repositório:**
   ```
   git clone https://github.com/CaioBalieir0/Projeto-SI
   ```
2. **Navegue até o Diretório do Projeto:**
   ```
   cd Projeto-SI
   ```
3. **Abra o arquivo index.html em seu navegador e utilize o sistema.**

## Estrutura dos Arquivos

* **index.html:** Página principal que contém o formulário de avaliação.
* **style.css:** Estilos personalizados para o sistema.
* **script.js:** Lógica do sistema, manipulação do DOM, e integração com o Chart.js.
* **chart.js:** Biblioteca para geração de gráficos.
